개발 단계 안내: 현재 이 프로젝트는 개발 및 API 접근 승인 준비 단계입니다. 아래 정책은 예정된 개인용 사용 구조를 설명하며, 실제 출시 전에 구현 상태에 맞게 수정됩니다.

1. 서비스 목적

Keyword Search Analyzer는 사용자가 입력한 키워드에 대해 Google Ads API를 통해 검색량 및 키워드 계획 정보를 조회하는 개인용 Firefox 확장프로그램 개발 프로젝트입니다.

2. 접근 예정인 데이터

사용자 승인 후 Google Ads 계정 접근 권한을 통해 키워드 계획 관련 데이터를 조회할 예정입니다. 사용자가 입력한 검색 키워드와 Google Ads 계정 식별정보가 요청 처리에 사용될 수 있습니다. Google 계정 비밀번호 자체는 앱에서 수집하지 않습니다.

3. 데이터 사용 목적

Google Ads 데이터는 사용자가 요청한 키워드 검색량, 월별 추이, 광고 경쟁도, 관련 키워드 정보를 표시하는 용도로만 사용할 예정입니다.

4. 저장 및 제3자 제공

계획된 구조에서는 OAuth 토큰을 사용자의 로컬 PC에 보관하고, 요청 처리를 위해 필요한 데이터를 Google Ads API에 전송합니다. 외부 광고·분석업체에 데이터를 판매하거나 제공하는 기능은 계획되어 있지 않습니다. 실제 구현 시 저장 여부, 기간, 보호 방법을 이 문서에 명확히 반영합니다.

5. 이용자 선택 및 문의

Google 계정의 제3자 앱 연결 관리에서 권한을 철회할 수 있습니다. 로컬에 저장된 토큰과 조회 데이터의 삭제 기능은 구현 시 제공할 예정입니다.
