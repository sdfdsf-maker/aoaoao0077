개인정보처리방침

최종 수정일: 2026년 10월 13일

현재 개발 상태: Keyword Search Analyzer는 개인용 Firefox 확장프로그램으로 개발 중이며, 아직 Google Ads API 실사용 연동이 완료되지 않았습니다. 다음 설명 중 '예정' 항목은 구현 계획으로, 현재 실제 수집이 이루어진다는 의미가 아닙니다. 기능을 실제 가동하기 전에 이 문서를 정확한 처리 현황에 맞게 수정하겠습니다.

1. 운영 목적과 범위

Keyword Search Analyzer는 사용자가 입력한 키워드를 바탕으로 Google Ads API에서 검색량, 월별 추이, 광고 경쟁도 및 연관 키워드를 조회하여 개인용 Firefox 확장프로그램에서 보여주기 위해 개발 중입니다. 공개 회원가입 서비스나 광고 캠페인 운영 서비스는 제공하지 않습니다.

2. 처리할 정보의 종류 및 취득 방법

실제 OAuth 연동 시 이용자가 Google 계정의 동의 화면에서 권한을 승인하면 Google Ads API 요청에 필요한 OAuth 접근 토큰 및 갱신 토큰, 승인된 광고 계정 식별자(고객 ID)를 처리할 예정입니다. 사용자가 직접 입력한 검색어 및 API가 반환한 키워드 통계도 처리할 예정입니다. Google 계정 비밀번호는 수집하지 않습니다.

이 웹사이트 자체에는 계정 생성 양식, 방문자 추적용 광고 태그 또는 별도의 사용자 행동 분석 코드를 설치하지 않았습니다. 다만 GitHub Pages 호스팅과 관련한 접속 로그 처리는 GitHub의 정책에 따를 수 있습니다.

3. 정보의 사용 목적

OAuth 자격증명은 Google Ads API 요청을 인증하는 데, 광고 계정 식별자는 요청 대상을 지정하는 데 사용됩니다. 입력한 검색어와 API의 응답은 월평균 검색량, 월별 검색량, 경쟁도 및 관련 키워드 결과를 표시하기 위해 사용합니다. 이와 무관한 광고 타기팅, 정보 판매 또는 사용자 프로파일링에는 사용하지 않습니다.

4. 정보의 전송 및 제3자 제공

서비스 구현 후 사용자가 조회를 요청하면 인증정보와 필요한 키워드·계정 식별정보가 Google Ads API로 전송될 예정입니다. 서버를 임대해 제3자에게 데이터를 재판매하거나 광고 업체에 제공할 계획은 없습니다. Google이 API 요청 정보를 처리하는 방식에는 Google 개인정보처리방침이 적용됩니다.

5. 저장 장소, 보관 기간 및 보호 조치

계획된 구현에서는 OAuth 토큰을 확장프로그램의 공개 소스나 GitHub 저장소에 포함하지 않고, 이용자 PC의 로컬 프로그램에 제한적으로 저장합니다. 구현 시 파일 접근 권한 및 비밀정보 보호 방법을 적용할 예정입니다. 검색 결과는 화면 표시를 위해 일시적으로 처리하며, 영구 검색 이력 저장 기능은 현재 계획되어 있지 않습니다.

OAuth 토큰은 이용자가 연결을 해제하거나 삭제를 요청할 때 로컬 저장소에서 삭제하도록 구현할 예정입니다. 앱이 실제 가동되기 전 토큰의 저장 형식, 보관 기간 및 삭제 절차를 최종 확정하고 본 정책에 반영합니다.

6. 이용자의 선택권과 삭제 방법

이용자는 Google 계정의 제3자 앱 연결 관리에서 해당 앱의 Google 계정 접근 권한을 철회할 수 있습니다. 권한 철회와 별개로 로컬 PC에 저장된 파일의 삭제가 필요할 수 있으며, 실제 프로그램 배포 전에 구체적인 삭제 방법을 안내할 예정입니다.

7. 아동 및 외부 사용자

이 프로젝트는 개발자의 개인용 도구로 계획되어 있으며, 일반 사용자를 대상으로 계정을 모집하거나 아동의 정보를 의도적으로 수집하는 서비스가 아닙니다.
