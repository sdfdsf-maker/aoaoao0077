1. 앱 개요

Keyword Search Analyzer는 키워드 데이터 확인을 목적으로 개발 중인 개인용 도구입니다. 현재 공개 서비스가 아니며 기능의 제공 여부와 내용은 변경될 수 있습니다.

2. 데이터의 성격

향후 제공되는 키워드 검색량과 경쟁도는 Google Ads API가 반환하는 데이터이며 정확한 실제 검색 횟수를 보장하지 않습니다.

3. 사용 조건

사용자는 Google API 및 관련 서비스 약관을 준수해야 합니다. 앱은 Google과 무관한 독립적인 개인 개발 프로젝트입니다.
