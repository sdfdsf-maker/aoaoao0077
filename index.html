Keyword Search Analyzer

키워드 검색량과 광고 경쟁도 정보를 확인하기 위한 개인용 Firefox 확장프로그램 개발 프로젝트입니다.

앱 소개

이 프로젝트는 Google Ads API를 활용해 사용자가 직접 입력한 키워드의 월평균 검색량, 월별 검색량, 광고 경쟁도 및 관련 키워드 정보를 확인하는 것을 목표로 합니다.

Firefox 확장프로그램과 사용자의 PC에서 실행되는 로컬 프로그램을 통해 API 연결을 구현할 예정입니다. 현재는 개발 및 API 접근 승인 준비 단계이며, 일반 사용자에게 서비스를 제공하고 있지 않습니다.

주요 개발 예정 기능

  • 직접 입력한 키워드의 월평균 검색량 조회
  • 월별 추이 그래프 표시
  • 광고 경쟁도 및 관련 키워드 표시
독립적인 개인 개발 프로젝트이며 Google이 제작·후원하는 공식 제품이 아닙니다.

데이터 및 개인정보

계정 인증과 Google Ads API 접근에 관한 사항은 개인정보처리방침에서 안내합니다. 실제 기능이 출시되기 전에 해당 방침을 구현 내용에 맞게 갱신합니다.
